# Fitness Tracker App

## Beskrivelse
Denne applikation er en træningsapp, hvor brugeren kan registrere og analysere sine træninger.

Appen består af:
- Frontend (Streamlit)
- Backend (FastAPI)
- Dataanalyse (Pandas, NumPy, Matplotlib)

## Funktioner
- Registrering af træning (øvelse, vægt, sæt, reps)
- Visualisering af vægtudvikling
- Analyse af træningsfrekvens

## Teknologier
- Python
- Streamlit
- FastAPI
- Pandas
- NumPy
- Matplotlib

## Installation
Installer alle nødvendige biblioteker:

pip install -r requirements.txt


## Hvordan projektet køres:

docker-compose up --build
